# Machine Learning Day 7 Projects

This repository contains my **Machine Learning Day 7** projects completed during my internship, focusing on **Unsupervised Learning** using the **K-Means Clustering Algorithm**.

---

## 📌 Projects Included

### 1️⃣ Customer Segmentation using K-Means Clustering

### Overview
This project groups customers into different clusters based on their Annual Income and Spending Score.

### Features
- Data Preprocessing
- Feature Standardization
- Elbow Method for Optimal K
- K-Means Clustering
- Cluster Visualization
- Cluster Centroids
- Customer Segmentation

### Technologies
- Python
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Output

- Elbow Method Graph
- Customer Clusters
- Cluster Centroids
- Segmented Customer Dataset
